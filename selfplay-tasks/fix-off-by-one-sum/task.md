# Task: fix-off-by-one-sum

`solution_scaffold/solution.py` contains `sum_to_n(n: int) -> int`, meant to return the sum of
all integers from `1` to `n` inclusive (e.g. `sum_to_n(3) == 1 + 2 + 3 == 6`). It has an
off-by-one bug. Fix it so all cases in `./test.sh` pass.

This task is deliberately a *bug fix*, not a from-scratch implementation — a different shape of
task than the other four in this suite, on purpose (residual Q2 — task variety, not just
difficulty, matters for what a self-play round can plausibly learn from).

Run `./test.sh` — exits 0 on success, non-zero on failure.
