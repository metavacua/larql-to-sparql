Modern operating systems present each process with a private linear address space, and the illusion is maintained by a combination of hardware and software that translates virtual addresses into physical frames on every memory reference. The page table is the central data structure in this scheme, and on a sixty-four bit machine it is almost always organised as a radix tree of four or five levels so that sparse address spaces do not require contiguous tables. Walking that tree on every access would be ruinously expensive, so the processor caches recent translations in a translation lookaside buffer, a small fully associative structure whose hit rate largely determines the practical cost of virtual memory. When a translation is absent the hardware either walks the tree itself or raises a fault for the kernel to service, and the resulting page fault may be minor, satisfied from a page already resident in memory, or major, requiring a transfer from backing store. Demand paging exploits the observation that programs touch only a fraction of their address space, so pages are materialised lazily on first reference rather than eagerly at load time.
